·Replace library
The dynamic library needs to be copied to a specific location in the installation directory.

The directory structure will be as follows:
	/opt/HuarayTech/MVviewer/
		├ bin
		│  ├ imageformats		libqgif.so,libqicns.so,libqico.so,libqjpeg.so,libqsvg.so,libqtga.so,libqtiff.so,libqwbmp.so,libqwebp.so,libqdds.so,libqjp2.so,libqmng.so
		│  └ platforms		libqminimal.so,libqlinuxfb.so,libqoffscreen.so,libqxcb.so
		│
		├ lib				liblog4cpp.so,libusb-1.0.so,libquazip.so
		│  ├ GenICam			libGCBase_gcc421_v3_0.so,libMathParser_gcc421_v3_0.so,libGenApi_gcc421_v3_0.so,libNodeMapData_gcc421_v3_0.so,liblog4cpp_gcc421_v3_0.so,libXmlParser_gcc421_v3_0.so,libLog_gcc421_v3_0.so
		│  └ Qt			libQt5Concurrent.so,libQt5Core.so,libQt5DBus.so,libQt5Gui.so,libQt5Network.so,libQt5Widgets.so,libQt5PrintSupport.so,libQt5XcbQpa.so,libQt5Xml.so,libqwt.so,libicudata.so,libicui18n.so,libicuuc.so
		│   
		   
If you want to replace library "libQt5Core.so", just replace the library to the corresponding directory above.
