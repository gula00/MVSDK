# Huaray / iRAYPLE MVSDK for Linux x86

Unofficial mirror of the vendor SDK package `MVviewer_Ver2.7.0.1_Linux_x86_Build20261029`.

## Contents

- `SDK/include`: C API headers with Chinese and English comments.
- `SDK/share/Python`: Python ctypes bindings and examples.
- `SDK/share/C`: C examples.
- `SDK/share/QT`: Qt examples.
- `SDK/bin` and `SDK/lib`: vendor binaries for x86 Linux.
- `SDK/module`: bundled driver components.
- `SDK/license`: bundled third-party license notices.
- `SDK/install.sh`: original vendor installer, without modifications.

The package includes 32-bit and 64-bit files. See the bundled readme files for installation details.
